이메일 API

POST /api/emails/load
이메일 파일 로드

mbox 파일을 로드하여 이메일 데이터를 처리합니다.

요청 예시:
{
  "filename": "emails.mbox"
}
응답 예시:
{
  "success": true,
  "message": "이메일 로드 완료",
  "total_emails": 150,
  "filtered_emails": 120
}
GET /api/emails/search
이메일 검색

키워드로 이메일을 검색합니다.

파라미터:
  • query - 검색 키워드
  • sender - 발신자 필터
  • date_from - 시작 날짜 (YYYY-MM-DD)
  • date_to - 종료 날짜 (YYYY-MM-DD)
응답 예시:
{
  "success": true,
  "results": [
    {
      "id": "email_001",
      "subject": "계약서 관련",
      "sender": "example@company.com",
      "date": "2024-01-15",
      "has_attachments": true
    }
  ],
  "total": 1
}

증거 API

GET /api/evidence
증거 목록 조회

생성된 증거 문서 목록을 조회합니다.

응답 예시:
{
  "success": true,
  "evidence_list": [
    {
      "id": "evidence_001",
      "evidence_number": "갑 제1호증",
      "title": "이메일 증거",
      "created_date": "2024-01-15",
      "file_path": "/evidence/갑제1호증.pdf"
    }
  ]
}
POST /api/evidence/generate
증거 생성

선택된 이메일들로 법정 증거 문서를 생성합니다.

요청 예시:
{
  "email_ids": ["email_001", "email_002"],
  "evidence_type": "email_batch",
  "party": "갑"
}
DELETE /api/evidence/{id}
증거 삭제

생성된 증거 문서를 삭제합니다.

파라미터:
  • id - 증거 문서 ID
응답 예시:
{
  "success": true,
  "message": "증거가 삭제되었습니다."
}

타임라인 API

GET /api/timeline
타임라인 생성

이메일 송수신 타임라인을 생성합니다.

파라미터:
  • format - 출력 형식 (json, html, csv)
  • date_from - 시작 날짜
  • date_to - 종료 날짜
